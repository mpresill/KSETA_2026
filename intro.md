# Welcome to KSETA PhD Course 2026

## EFT and Experimental Measurements

This course provides an introduction to Effective Field Theory (EFT) and experimental measurements for PhD students.

The course covers:
- Theoretical foundations of EFT
- Practical applications in particle physics
- Experimental measurement techniques
- Data analysis methods

## Course Information

- **Target Audience**: PhD students in particle physics
- **Duration**: To be announced
- **Format**: Lectures and hands-on exercises using Jupyter notebooks

## Course Structure

This course material is organized into the following sections:

- **Course Overview**: Detailed course objectives and structure
- **Introduction to EFT**: Jupyter notebook with interactive examples
- **Experimental Measurements**: Hands-on data analysis with Python
- **Slides**: Course presentation slides (to be added)
- **Tutorial**: Additional hands-on tutorial materials
- **Supplementary Material**: Additional resources and materials
- **References**: Bibliography and references
